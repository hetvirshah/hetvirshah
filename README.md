### About Me

I'm a software developer with 2.5+ years of experience building and shipping production software, from white-label apps to a real-time fleet tracking platform that I own end-to-end as the sole developer.

My core stack is **Flutter and Dart**, and I also work with **React** for web interfaces. I'm now building my cloud skills with **AWS** and preparing for the **AWS Solutions Architect Associate (SAA-C03)** exam.

I enjoy working across the full development cycle: shaping the UI, integrating APIs, handling real-time data and optimizing performance and cost.

Outside of development, I read a lot of novels and explore new technologies.
